# 📊 Desafio de Análise de Vendas - Alura Store

Este projeto tem como objetivo ajudar o Sr. João a decidir qual loja vender, com base na análise de dados de vendas das quatro lojas da Alura Store.

## 🔍 O que foi analisado
- Faturamento total por loja
- Vendas por categoria
- Média de avaliações dos clientes
- Produtos mais e menos vendidos
- Frete médio por loja

## 🛠 Tecnologias usadas
- Python
- Google Colab
- Pandas
- Matplotlib

## 🚀 Como executar
1. Abra o notebook no Google Colab.
2. Execute todas as células (inclusive as de importação dos dados).
3. Visualize os gráficos e leia o relatório final em Markdown.

## 📁 Estrutura
- `notebook.ipynb` → análise completa + relatório
- `dados/` → arquivos CSV com os dados das lojas
- `README.md` → este arquivo

## 📝 Conclusão
Com base nas análises, é possível identificar a loja com menor desempenho e recomendar sua venda para que o Sr. João invista em um novo negócio.
